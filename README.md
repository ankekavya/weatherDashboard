# 🌦️ SkyCast — Weather Dashboard 2.0

**Weather, Made Clearer.**

SkyCast is a modern, responsive weather dashboard built using HTML, CSS and JavaScript. It provides real-time weather information, hourly forecasts and a 7-day weather outlook using the Open-Meteo API.

## 🌐 Live Demo

[**Visit SkyCast Weather Dashboard**](https://ankekavya.github.io/weatherDashboard/)

## 📌 Project Overview

SkyCast makes checking weather simple and interactive through a modern dashboard featuring a premium dark interface, attractive weather icons, responsive layouts and real-time weather updates.

Users can search for different cities, check their current location's weather and explore upcoming weather conditions.

## ✨ Features

- 🌤️ Real-time weather information for different cities.
- 📍 Automatic weather display for Bengaluru on page load.
- 🔎 Search functionality for cities worldwide.
- 📌 Special location support for Pulivendula and HSR Layout.
- 🌡️ Current temperature and weather conditions.
- 🌡️ Feels-like temperature.
- 💧 Humidity information.
- 💨 Wind speed details.
- ☀️ UV index and visibility information.
- 🌡️ Atmospheric pressure.
- ⏰ 24-hour hourly weather forecast.
- 📅 7-day weather forecast.
- 🌡️ Daily maximum and minimum temperatures.
- 🌅 Sunrise and sunset timings.
- 📍 Current location detection using browser geolocation.
- 🔄 Celsius and Fahrenheit temperature conversion.
- 🏙️ Quick city selection.
- 📱 Responsive design for desktop, tablet and mobile.
- ✨ Animated weather icons and modern dashboard cards.

## 🌍 Weather API Integration

SkyCast uses Open-Meteo APIs to retrieve weather information and city coordinates.

**Weather Forecast API:**
https://open-meteo.com/en/docs

**Geocoding API:**
https://open-meteo.com/en/docs/geocoding-api

The standard Open-Meteo endpoints used in this project do not require an API key.

## 🚀 How to Run Locally

Follow these steps to run SkyCast on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/ankekavya/weatherDashboard.git
```

**2. Open the project folder**

Open the downloaded project folder in Visual Studio Code.

**3. Install Live Server**

Install the Live Server extension in VS Code if you haven't already.

**4. Run the project**

Right-click on `index.html` and select **Open with Live Server**.

**5. Explore the dashboard**

Search for your favourite city and explore its current weather, hourly forecast and weekly predictions.
